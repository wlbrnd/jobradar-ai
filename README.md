# JobRadar AI

RAG assistant for searching and analyzing Russian IT job vacancies.

## Project goals

- Collect job vacancies from Russian job platforms.
- Clean and store vacancy data.
- Build keyword and semantic search.
- Generate answers grounded in retrieved vacancy descriptions.
- Evaluate retrieval quality.

## Planned stack

- Python
- SQLite
- FastAPI
- BM25 and vector search
- Sentence Transformers
- Streamlit
- pytest

## Data sources

- HeadHunter API
- Работа России
